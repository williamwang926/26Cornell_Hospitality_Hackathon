# Data Rights and Repository Policy

## Raw-data status

The raw review export used by this prototype is proprietary to **Hilton** and was made available to the project team for the **2026 Hospitality Hackathon**. It is not open data and is not redistributed through this repository.

The repository intentionally excludes:

- the raw CSV export and all copies/archives of it;
- processed review-level files, model caches, and trained models derived from raw guest text;
- guest text, guest identifiers, property identifiers, screenshots containing guest information, and credentials.

## Permitted repository contents

The private repository may contain source code, non-sensitive configuration, methodology documentation, an issue taxonomy, editable solution assumptions, and aggregate/generated results that have been reviewed for disclosure risk.

Before any change from private to public visibility, obtain written authorization from Hilton/the hackathon organizer and conduct a fresh disclosure review. A public repository should remove or aggregate any property-level output unless explicit permission covers it.

## Attribution

Suggested wording:

> “Underlying guest-feedback data are proprietary to Hilton and were provided for the 2026 Hospitality Hackathon. The raw data are not included or redistributed.”

This statement is an attribution and handling notice; it does not grant any data license.
